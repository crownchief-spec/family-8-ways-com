親子寫真客戶案件管理

本系統採用 Markdown 檔案式管理。每一組客戶案件都是一個獨立的 MD 檔案，可用來產生客戶專區、合約確認頁、作品交件頁，也可以在結案後選擇轉為公開作品集文章。

這裡是攝影師內部管理頁，不是給客戶看的頁面。新增或修改客戶案件時，請在專案的 clients Markdown 資料夾中建立或編輯對應 .md 檔案。

狀態篩選

建議用以下狀態管理進度：詢問中、已報價、已收訂、已簽約、已拍攝、修圖中、已交件、已結案。

如何新增客戶案件

  1. 複製一份既有的客戶 MD 範本。
  2. 將檔名改成「客戶代稱-拍攝日期.md」，slug 預設使用「yyyy-mm-dd + 主題」，例如：2026-01-01family。
  3. 修改 frontmatter 中的拍攝日期、方案、費用、地點、付款狀態與合約狀態；若同日期 slug 已存在，請依內容更換後綴主題名稱。
  4. 儲存後網站會自動產生客戶專區。
  5. 將客戶專區連結傳給客人即可完成合約確認與後續交件。

客戶 Markdown 路徑：src/content/clients/*.md（舊版相容：content/clients/*.md）

從 LINE／訊息對話產生客戶 MD

  1. 複製與客戶討論的 LINE、Messenger、Email 或電話紀錄摘要。
  2. 打開 Cursor。
  3. 貼上對話，並輸入：「請使用 Family Client MD Generator，根據這段對話建立新的 content/clients Markdown 客戶案件。」
  4. Cursor 會自動讀取 docs/family-service-knowledge.md，判斷方案、價格、成品、包車、付款與待確認事項。
  5. Cursor 會產生一個新的客戶 MD。
  6. 網站會根據該 MD 產生客戶專屬合約與作品交件頁。
  7. 檢查後，把單一客戶頁連結傳給客戶。

複製客戶案件 MD 範本

空白欄位可以刪除，不一定要保留。前端會自動隱藏空欄位。
