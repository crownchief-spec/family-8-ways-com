親子寫真合約產生系統

此頁為攝影師內部流程說明，不提供客戶公開填寫。

合約產生流程

  1. 在 Cursor 貼上客戶對話或拍攝需求。
  2. Cursor 依照 docs/family-service-knowledge.md 判斷方案、價格、成品、付款、特殊條款。
  3. Cursor 產生 content/clients/[slug].md。
  4. 網站依 MD 自動產生客戶專屬頁。
  5. 檢查內容後，把單一客戶頁連結傳給客戶。
  6. 客戶只會看到自己的合約確認與交件頁。

合約頁包含

  • 拍攝日期、時間、地點、方案
  • 總費用、訂金、尾款、成品內容
  • 付款方式、合約確認、電子簽名
  • 作品公開授權、拍攝前準備、拍攝後交件連結

不要公開的內容

  • 全部客戶列表與其他客戶資料
  • 客戶電話與 Email
  • 內部備註與完整對話紀錄
  • 成本與內部報價判斷
